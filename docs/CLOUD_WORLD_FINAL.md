## Visual API (M5 compatible)

- `applyAllocation({taskIndex, taskId, vmIndex, selectedVM, executionTime, vmLoads, step, partialAssignment})` returns true on acceptance; invalid input returns false and sets `lastVisualizationError`, leaving the prior scene intact. VM alias values must agree. Task index 0..7, VM index 0..2; seconds/loads finite and nonnegative. Partial assignment accepts the growing prefix emitted by M4.
- Each task has one replaceable motion record (1.4 simulation seconds, eased arc). Repeated Step replaces that task's target from its current position; separate tasks can move concurrently. Actor and label move together. Placement slots are deterministic per task index, so duplicates cannot accumulate. Latest caller loads display immediately; no delayed completion callback can overwrite newer loads.
- `resetVisualization()` cancels all eight motions, clears highlights, restores task queue positions and zero loads.
- `applySchedule({assignments,vmLoads,makespan})` validates and places a complete schedule immediately, supporting replay/seek snapshots. Returns false on malformed payload.
- `setPreviewMode(true)` explicitly labels demo values. Normal mode labels external data without claiming that this renderer computes optimization.
